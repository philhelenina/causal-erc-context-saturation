# Legacy feature utilities

This directory contains older WordNet-Affect and Sentence-RoBERTa feature-generation utilities used during development. They are not required for the main TMLR reproducibility path.

External lexicons are not redistributed here. To reproduce these legacy experiments, obtain the external resources separately and place them locally, for example:

```text
legacy/features/external/wna_lexicon.csv
legacy/features/external/wordnet_affect.xml
```
